# 使用指南与故障排查

[返回项目首页](../README.md)

## 登录与凭据

- 仅支持中国大陆 +86 手机号和单账号。打开登录弹窗不会发送短信，需点「发送验证码」。每次登录流程最长 5 分钟；人工验证不超过 2 分钟。发送间隔至少 60 秒，每轮最多提交 5 次短信验证码。
- 若出现极验，请在弹窗内手动完成。验证加载失败或过期时，取消后重新开始；发送结果不明时先等短信，不要连续重发。
- 新登录在只读校验通过后才替换旧登录。若大别野已启用，社区凭据校验也必须通过；关闭大别野时，社区校验失败仅给出警告。失败或取消不会覆盖旧登录。
- 插件不会定期续期或续期 SToken 本身。出现登录失效或缺少社区凭据时，可重新短信登录；缺少社区凭据不会阻止游戏签到。
- 「删除登录」需二次确认，会移除保存凭据和账号相关缓存。卸载插件与删除账号状态是两件事。

手机号、短信码和验证结果只用于本轮登录，不写入持久化状态、浏览器存储或 URL。长期登录凭据由宿主持有，以明文保存在默认 `~/.dsh/mys-checkin/state.json`；保护本机和备份，勿公开该文件。极验在验证时需要连接第三方官方资源。

## 签到与结果

- 手动和定时都使用已保存的签到项目。保存中、保存失败或没有勾选项目时不能手动执行。另一面板改过配置时，核对最新设置后再重新应用；不会自动重放旧草稿。
- 默认定时窗口为 `18:00–18:30`，可设最多 4 个窗口。启用错过补跑时，错过窗口后会延迟 3–10 分钟安排。自动尝试每日最多一次；手动不消耗自动尝试机会，游戏与大别野各自判断完成情况。
- 大别野的去重使用 `Asia/Shanghai` 自然日；定时任务的每日机会使用所配置的时区。手动和定时共用单实例互斥锁，请勿在多个实例中对同账号并行签到。
- 结果按游戏与大别野分别记录。米游币快照是账号级查询，不计算本轮赚取，也不证明已到账。过期快照或查询失败时显示历史信息。

| 情况 | 建议操作 |
| --- | --- |
| 宿主端不兼容 | 确认客户端与宿主加载同一插件版本，按 DSH 提示重载或重启。 |
| 设置保存失败或已变化 | 查看已保存设置，重新应用需要的勾选后再手动签到。 |
| 游戏尚无可用角色、首次绑定 | 确认账号及国服角色；首次绑定按面板提示在官方 App 处理。 |
| 签到要求人机验证 | 本轮停止剩余写操作。请到官方 App 完成验证；登录弹窗的极验不用于继续签到。 |
| 大别野结果不明 | 先到官方 App 核对，再决定是否手动重试。对仍保留本地状态的当前账号，同一上海自然日不会自动重复该写入；退出或换号会清除账号相关记录。 |
| 需要检查连通性 | 「检测接口与登录」会请求只读绑定接口，不会执行签到，也不是离线自检。 |

## 升级与回退

旧配置只有在社区已启用且已选中大别野时，才会保留启用；其他分区不再签到，也不作为大别野的历史结果。有效旧凭据可以继续使用。升级或退回旧版前先**暂停自动签到并确认保存**；旧版可能恢复多分区默认值，重新启用自动签到前请核对所有项目。Git 历史不包含登录状态，不能用来恢复已删除的凭据。
