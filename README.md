# 米游社签到 · DSH 插件

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

在 DeepSeek Harness（DSH）侧栏为国服游戏和大别野（米游币）签到。支持中国大陆 `+86` 短信登录，一个面板配置手动及定时签到。运行时使用 Node.js 22 或更高版本，无第三方运行时依赖。

## 功能

- **游戏签到**：支持原神、崩坏：星穹铁道、绝区零、崩坏 3、未定事件簿和崩坏学园 2 国服。
- **大别野（米游币）**：默认不勾选，仅支持这一个社区分区。不看帖、不点赞、不分享、不发帖。
- **统一配置**：在「签到项目」勾选游戏和大别野。「立即签到」和定时任务使用同一组已保存的项目。
- **定时签到**：在所设时间窗口内随机执行。面板分别显示上次游戏和大别野结果，以及账号级米游币快照。

## 安装

1. 准备包含本 README 所述功能的源码目录。旧标签可能仍是扫码版，请核对所选版本。
2. 在 DSH 的「插件」中选择添加本地插件，指向包含 `package.json` 的项目根目录。
3. 启用 `@local/dsh-mys-checkin`。按 DSH 提示重载或重启，然后打开侧栏的「米游社签到」。

## 使用

1. 点「短信登录」，输入大陆手机号，手动发送并填写 6 位验证码。若遇到官方极验，请亲自完成；插件不会绕过验证或自动重发短信。
2. 在「签到项目」勾选目标，等待面板确认设置已保存。
3. 点「立即签到」，或打开自动签到并设置时间窗口。关闭自动签到不会禁用手动签到。

从旧版升级时，只有原本已启用且选中过大别野的配置会继续勾选大别野；不会把其他旧分区自动改成大别野。有效的旧登录不必重登。

> [!IMPORTANT]
> 长期登录凭据以明文保存在宿主本地状态文件（默认 `~/.dsh/mys-checkin/state.json`），不是系统钥匙串。请勿把它上传到 GitHub 或作为 Issue 附件。签到接口显示「接受」不代表米游币已到账，请以米游社 App 为准。
